# Проект "Приложение для анализа банковских операций"

## Описание:
Проект содержит заготовки под заполнение различных web-страниц, связанных с транзакциями клиента и ситуацией на финансовом рынке

## Установка:

1. Клонируйте репозиторий: 
```
git clone https://github.com/iGhostCat/trans_analysis.git
```

2. Разверните виртуальное окружение проекта:
```
pip install poetry
poetry shell
```
3. Проведите тестирование корректности работы представленного функционала:
```
pytest
```

## Конвертация валют:

1. Создайте в корне локального репозитория файл .env и поместите в него свой личный API-ключ с сайта https://site.financialmodelingprep.com/developer/docs в формате: 
    API_KEY = abc1234567
